# 📄 AI Resume Analyzer

An AI-powered web application that analyzes resumes and provides useful career insights.

## Features

- Upload a resume
- Extract resume information
- Identify skills
- Match skills with a target job
- Find missing skills
- Generate improvement suggestions

## Tech Stack

- Python
- Streamlit
- NLP
- AI
